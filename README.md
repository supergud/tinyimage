# TinyImage 🖼️

繁體中文 | [English](README.en.md)

圖片壓縮與裁切工具，所有處理都在瀏覽器端完成，支援批次處理、智慧縮放、中文檔名清理。

線上使用：<https://tinyimage.eat2die.com>

## 功能

### 壓縮 / 縮小
- 以 Canvas 重新編碼壓縮圖片（JPEG q0.82、PNG、WebP q0.8）
- 設定最大邊長後等比縮放，不超過指定像素
- 同時設定寬高則縮放至符合框內（等同 `fit: inside`）
- 不設定尺寸則只做壓縮，維持原始比例

### 裁切並壓縮
- 指定寬度與高度，裁切為精確尺寸（等同 `fit: cover`）
- 可選裁切錨點：置中、四角、四方向

### 其他特點
- 支援批次處理，顯示原始與輸出尺寸對比
- 下載檔名自動帶入實際輸出尺寸（如 `photo_resized_2000x1333.jpg`）
- 自動清除中文檔名中的特殊符號
- 全部下載打包成 ZIP
- 圖片不會上傳到伺服器，零隱私疑慮

## 支援格式

瀏覽器能解碼的格式皆可輸入（JPEG · PNG · WebP · GIF · AVIF 等）。輸出：JPEG / PNG / WebP 維持原格式，其他一律轉 JPEG。
